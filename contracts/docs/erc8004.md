# ERC-8004 IdentityRegistry on RHC (chain 4663)

Proxy `0x8004A169FB4a3325136EB29fA0ceB6D2e539a432` (EIP-1967). Implementation slot
`0x3608...2bbc` holds `0x7274e874ca62410a93bd8bf61c69d8045e399c02`. Probed at block 95,810,184 on
2026-10-23. The Blockscout explorer API was unreachable from the dev VPS (HTTP 000), so the ABI was
found by `cast call` probes only.

## Findings

- `name()` = "AgentIdentity", `symbol()` = "AGENT", `getVersion()` = "2.0.0", `owner()` = 0x547289319C3e6aedB179C0b8e8aF0B5ACd062603 (registry admin, not used by Spindle).
- ERC-721: `supportsInterface(0x80ac58cd)` = true; `ownerOf(uint256)` works. Reverts for unminted ids (the probes returned values for ids 0 and 1, so ids may start at 0).
- `tokenURI(uint256)` works; `getAgentWallet(uint256)` returns an address; `getMetadata(uint256,string)` returns bytes. `totalSupply()` is NOT implemented.
- Minting is public: `register()`, `register(string)` and `register(string,(string,bytes)[])` all simulate OK from an arbitrary EOA (about 15k gas simulated by `cast call`; ids around 15014 at probe time). The fork test mints via `register()` and links it.
- Transient storage (TSTORE/TLOAD) works on RHC (eth_call with code override), so `ReentrancyGuardTransient` and `evm_version = cancun` are fine.

## Surface Spindle relies on

Only `ownerOf(uint256) returns (address)` (`IERC8004Identity`). `SpindleRegistry.linkIdentity` requires `ownerOf(agentId) == msg.sender`. No deviation from the spec. Note `ownerOf` returns the current NFT holder, so a link is a snapshot: it is not revoked if the NFT is later transferred.
